# autorun v1.0.0rc1

Date: 2026-08-15

## Upgrade notes

Existing `/ar` command spellings and task state remain compatible with v0.12.0;
this RC requires no state migration command.

The optional PDF dependency sets changed:

- The `cpu` extra now installs `pypdf`. The CLI backend id remains `pypdf2`, so
  existing `--backends pypdf2` commands still work.
- The `gpu` extra installs docling on Linux and Windows. It installs no backend
  on macOS while docling's model stack pins an advisory-affected transformers
  4.x release.
- The `marker` backend remains discoverable for separately managed installs,
  but no published extra installs marker-pdf while it pins Pillow below the
  first fully patched release.

## User-visible changes

- Pi installs an owned extension with in-process tool vetoes, display-only
  commands, attributed continuation, compaction-aware transcripts, and
  daemon-backed `TaskCreate`, `TaskUpdate`, and `TaskList` tools.
- Pi task acknowledgments report Python-confirmed state. Dependency-ready work
  appears before blocked tasks and bounded terminal history.
- Prime Agent (PrimeIntellect's build of the Pi coding agent) installs the
  same extension under `~/.prime/agent/extensions/ar/` with its own
  `cliType: "prime"` identity; `autorun --install --prime` selects it alone.
- Scope durations accept day units (`2d`, `1d12h`) in `/ar:ok`, `/ar:no`,
  `/ar:globalok`, `/ar:cache`, and `/ar:task pause`.
- A user-authored skill in `~/.agents/skills` no longer gains a same-named
  native copy on harnesses that read both routes; the withheld copy is
  reported as a preserved conflict and stale duplicates retire on reinstall.
- `autorun` publishes to PyPI through TestPyPI-first OIDC trusted publishing. It
  is the only distribution: PDF extraction ships inside it as `autorun[pdf]`, so
  a plain install pulls no extraction dependency at all.
- Concurrent hook state uses JSON or SQLite storage with migration and rollback
  receipts. Cross-process tests cover reminder claims, task writes, Stop
  enforcement, and session isolation.
- Install and uninstall ownership covers the supported harness routes without
  replacing user-authored files.

## RC installation

```bash
claude plugin marketplace add https://github.com/ahundt/autorun.git
claude plugin install ar@autorun
```

Optional Claude companion:

```bash
claude plugin install pdf-extractor@autorun
```

Python tools:

```bash
uv tool install autorun

# With the PDF extraction backends:
uv tool install --force 'autorun[pdf]'
```

For source installations, see the repository README. Existing large or busy
JSON-state installations can inspect the configured backend while their scoped
daemon is stopped:

```bash
autorun --state-status
autorun --state-migrate
autorun --state-status
```

Rollback remains available with `autorun --state-rollback`.

## Verification

The release gate covers Python 3.10 through 3.14 on Ubuntu, Python 3.13 on macOS
and Windows, coverage, release artifacts, tmux integration, state benchmarks,
TestPyPI installation, and scratch-home marketplace installation. Paid model
calls and retired Gemini model calls remain opt-in.
