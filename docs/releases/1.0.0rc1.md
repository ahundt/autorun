# autorun v1.0.0rc1

This release candidate hardens autorun's multi-harness runtime, installer, and
state lifecycle ahead of 1.0. It supports Claude Code/Desktop Code, Codex,
Gemini/Qwen-family harnesses, Antigravity, ForgeCode, OpenCode, and Pi on
supported Linux, macOS, and Windows environments.

## Highlights

- Concurrent hook state has explicit JSON/SQLite backends, durable migration
  and rollback receipts, bounded hook deadlines, and cross-process tests for
  emit-once reminders and message claims.
- Claude cache fallback is non-destructive: failed native registration cannot
  replace an existing managed cache or remove its `.venv`.
- Windows daemon spawn, loopback transport, console encoding, prompt detection,
  process identity, plugin paths, and plan paths have platform contracts.
- Install and uninstall ownership is symmetric across supported harnesses and
  preserves user-authored files.
- Pi has an owned native extension with in-process tool vetoes, display-only
  commands, attributed continuation, compaction-aware transcripts, and
  daemon-backed `TaskCreate`, `TaskUpdate`, and `TaskList` tools.
- Pi task acknowledgments report Python-confirmed state; dependency-ready work
  precedes blocked tasks and bounded terminal history.
- Release artifacts are built twice for byte identity, installed in isolated
  environments, and checked for metadata, licensing, and runtime inventory.
- `autorun` and `pdf-extractor` publish as separate PyPI distributions
  through TestPyPI-first OIDC trusted publishing. PDF extraction backends are
  optional extras rather than required downloads. The `cpu` extra uses
  maintained `pypdf`; marker-pdf is omitted while it pins an unpatched Pillow,
  and docling is excluded on macOS while its model stack pins transformers 4.x.

## RC installation

```bash
claude plugin marketplace add https://github.com/ahundt/autorun.git
claude plugin install ar@autorun
```

Optional companion:

```bash
claude plugin install pdf-extractor@autorun
```

Python CLI installation:

```bash
uv tool install autorun
uv tool install 'pdf-extractor[cpu]'
```

For source installations, see the repository README. Existing large or busy
JSON-state installations can inspect and migrate the state backend while their
scoped daemon is stopped:

```bash
autorun --state-status
autorun --state-migrate
autorun --state-status
```

Rollback remains available with `autorun --state-rollback`.

## Verification

The candidate is gated by the seven-platform/Python matrix plus coverage,
release-artifact, tmux-integration, state-benchmark, TestPyPI installation, and
scratch-home marketplace checks. The release must be published as a GitHub
prerelease so stable installs do not select it while RC installations can
discover newer RCs.
