# Plan Export (`/ar:pe`)

$ARGUMENTS

Short spelling of `/ar:planexport`; both route through the same dispatcher,
settings store, and platform-specific renderer. Plans are exported
automatically when you exit plan mode. See `/ar:planexport` for the full
subcommand table and template variables.
